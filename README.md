# Plaxswap developer quickstart

Source of https://plaxswap-com.github.io/, a short guide to accepting crypto payments with the Plaxswap payment API: create a payment, send the customer to hosted checkout, verify the signed webhook, and test every outcome in test mode.

- API docs: https://plaxswap.com/developers/payments
- Example code: https://github.com/plaxswap-com/crypto-payment-gateway-integration
